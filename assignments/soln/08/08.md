# 1️⃣ Calculate the Area of a Circle

### Solution

```python
# ============================================================
# Question 1: Calculate the Area of a Circle
# ============================================================

# Function to calculate the area of a circle
def calculate_area(radius):

    # Value of Pi
    pi = 3.14

    # Calculate the area
    area = pi * radius * radius

    # Return the calculated area
    return area


# Get radius from the user
radius = float(input("Enter radius: "))

# Call the function and store the returned value
area = calculate_area(radius)

# Display the result
print("Area =", area)
```

### Sample Output

```text
Enter radius: 5
Area = 78.5
```

### Key Concept

The function receives `radius` as a **parameter** and returns the calculated area.

```python
area = calculate_area(radius)
```

# 2️⃣ Check Eligibility to Vote

### Solution

```python
# ============================================================
# Question 2: Check Eligibility to Vote
# ============================================================

# Function to check voting eligibility
def check_voting_eligibility(age):

    # Check whether the age is 18 or above
    if age >= 18:
        return "Eligible to Vote"
    else:
        return "Not Eligible to Vote"


# Get age from the user
age = int(input("Enter age: "))

# Call the function
result = check_voting_eligibility(age)

# Display the returned result
print(result)
```

### Sample Output

```text
Enter age: 20
Eligible to Vote
```

### Key Concept

The `if-else` is inside the function:

```python
if age >= 18:
    return "Eligible to Vote"
else:
    return "Not Eligible to Vote"
```

The function returns a **String**.

# 3️⃣ Calculate Total, Average and Result

### Solution

```python
# ============================================================
# Question 3: Calculate Total, Average and Result
# ============================================================

# Function to calculate total, average and result
def calculate_result(marks1, marks2, marks3):

    # Calculate total marks
    total = marks1 + marks2 + marks3

    # Calculate average
    average = total / 3

    # Determine Pass or Fail
    if average >= 40:
        result = "Pass"
    else:
        result = "Fail"

    # Return all three values
    return total, average, result


# Get marks from the user
english = int(input("Enter English Marks: "))
maths = int(input("Enter Maths Marks: "))
science = int(input("Enter Science Marks: "))

# Call the function
total, average, result = calculate_result(
    english,
    maths,
    science
)

# Display the results
print("Total =", total)
print("Average =", round(average, 2))
print("Result =", result)
```

### Sample Output

```text
Enter English Marks: 75
Enter Maths Marks: 80
Enter Science Marks: 65

Total = 220
Average = 73.33
Result = Pass
```

### Important Concept – Returning Multiple Values

The function returns:

```python
return total, average, result
```

These values are received here:

```python
total, average, result = calculate_result(
    english,
    maths,
    science
)
```

This is called **unpacking the returned values**.

# 4️⃣ Find the Sum of Numbers

### Solution

```python
# ============================================================
# Question 4: Find the Sum of Numbers
# ============================================================

# Function to calculate the sum from 1 to n
def calculate_sum(n):

    # Variable to store the running total
    total = 0

    # Loop from 1 to n
    for i in range(1, n + 1):

        # Add the current number to total
        total = total + i

    # Return the final total
    return total


# Get the value of n from the user
n = int(input("Enter n: "))

# Call the function
result = calculate_sum(n)

# Display the result
print("Sum =", result)
```

### Sample Output

```text
Enter n: 10
Sum = 55
```

### How the Loop Works

For `n = 5`:

```text
total = 0

i = 1 → total = 1
i = 2 → total = 3
i = 3 → total = 6
i = 4 → total = 10
i = 5 → total = 15
```

The function finally returns:

```text
15
```

# 5️⃣ Simple Calculator Using Functions

### Solution

```python
# ============================================================
# Question 5: Simple Calculator Using Functions
# ============================================================


# Function for addition
def add(a, b):
    return a + b


# Function for subtraction
def subtract(a, b):
    return a - b


# Function for multiplication
def multiply(a, b):
    return a * b


# Function for division
def divide(a, b):
    return a / b


# Get two numbers from the user
first_number = float(input("Enter first number: "))
second_number = float(input("Enter second number: "))


# Call each function and display the result
print("Addition =", add(first_number, second_number))
print("Subtraction =", subtract(first_number, second_number))
print("Multiplication =", multiply(first_number, second_number))
print("Division =", divide(first_number, second_number))
```

### Sample Output

```text
Enter first number: 20
Enter second number: 5

Addition = 25.0
Subtraction = 15.0
Multiplication = 100.0
Division = 4.0
```

### Key Concept

Instead of writing all calculations in one large program, we have divided the program into four small functions:

```text
add()
subtract()
multiply()
divide()
```

This demonstrates the main purpose of functions:

> **Breaking a large problem into smaller reusable tasks.**

## ⚠️ Small Improvement for Zero

The assignment says **Positive or Negative**, but mathematically `0` is neither positive nor negative.

A slightly better version is:

```python
def analyze_number(number):

    if number > 0:
        print("Positive")
    elif number < 0:
        print("Negative")
    else:
        print("Zero")

    if number % 2 == 0:
        print("Even")
    else:
        print("Odd")
```

For example:

```text
Enter a number: 0

Zero
Even
```

I would recommend teaching this version because it reinforces `if-elif-else`.

# 🎯 Important Concepts for Students

### 1. Defining a Function

```python
def greet():
    print("Hello")
```

### 2. Calling a Function

```python
greet()
```

### 3. Passing an Argument

```python
greet("Ahmed")
```

when the function is:

```python
def greet(name):
    print("Hello", name)
```

### 4. Returning a Value

```python
def square(number):
    return number * number
```

### 5. Using the Returned Value

```python
result = square(5)

print(result)
```

## ⭐ The Main Idea

Students should understand the difference between these two approaches:

### Without Functions

```text
Large Program
     ↓
Many statements
     ↓
Difficult to reuse
```

### With Functions

```text
              Program
                 ↓
       ┌─────────┼─────────┐
       ↓         ↓         ↓
    Function  Function  Function
       ↓         ↓         ↓
    Task 1     Task 2    Task 3
```

The goal of Functions is not simply to learn the `def` keyword. The important programming skill is **breaking a problem into smaller, reusable pieces**.
