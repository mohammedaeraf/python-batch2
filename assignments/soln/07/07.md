## 1️⃣ Display Characters of a String

### Solution

```python
# ============================================================
# Question 1: Display Characters of a String
# ============================================================

# Ask the user to enter a word
word = input("Enter a word: ")

print("\nCharacters:")

# Loop through each character in the word
for character in word:
    print(character)
```

### Explanation

The `for` loop automatically visits each character of the String one by one.

For:

```python
word = "Python"
```

the loop processes:

```text
P
y
t
h
o
n
```

# 2️⃣ Count Vowels in a String

### Solution

```python
# ============================================================
# Question 2: Count Vowels in a String
# ============================================================

# Ask the user to enter some text
text = input("Enter text: ")

# Variable used to count the vowels
vowel_count = 0

# Loop through every character in the String
for letter in text:

    # Check whether the character is a vowel
    # Both uppercase and lowercase vowels are included
    if letter in "aeiouAEIOU":
        vowel_count = vowel_count + 1

# Display the final count
print("Number of Vowels =", vowel_count)
```

### Example

For:

```text
Education
```

the vowels are:

```text
E
u
a
i
o
```

Therefore:

```text
Number of Vowels = 5
```

### Important Concept

This is an example of using a **counter**:

```python
vowel_count = vowel_count + 1
```

Every time a vowel is found, the counter increases by `1`.

# 3️⃣ Count a Particular Character

### Solution

```python
# ============================================================
# Question 3: Count a Particular Character
# ============================================================

# Ask the user to enter some text
text = input("Enter text: ")

# Ask the user which character should be searched
search_character = input("Enter character to search: ")

# Counter to store the number of occurrences
count = 0

# Loop through every character in the text
for character in text:

    # Compare the current character with the
    # character entered by the user
    if character == search_character:
        count = count + 1

# Display the result
print("Occurrences of", search_character, "=", count)
```

### Example

Input:

```text
Enter text: banana
Enter character to search: a
```

The program checks:

```text
b → No
a → Yes
n → No
a → Yes
n → No
a → Yes
```

Therefore:

```text
Occurrences of a = 3
```

### 💡 Important

The program compares **one character at a time**:

```python
character == search_character
```

# 4️⃣ Reverse a String

## Solution Using a Loop

```python
# ============================================================
# Question 4: Reverse a String
# ============================================================

# Ask the user to enter a word
word = input("Enter a word: ")

# Start with an empty String
reverse = ""

# Loop through each character in the word
for character in word:

    # Add the current character to the beginning
    # of the reverse String
    reverse = character + reverse

# Display the original and reversed Strings
print("\nOriginal =", word)
print("Reverse =", reverse)
```

### Example

For:

```text
Python
```

the loop works approximately like this:

```text
Initially:  ""

P → "P"
y → "yP"
t → "tyP"
h → "htyP"
o → "ohtyP"
n → "nohtyP"
```

Final result:

```text
Reverse = nohtyP
```

## Challenge Solution – Using Slicing

Once students understand the loop-based solution, show them the shorter Python approach:

```python
# Ask the user to enter a word
word = input("Enter a word: ")

# [::-1] reverses the String
reverse = word[::-1]

print("Original =", word)
print("Reverse =", reverse)
```

This is a good opportunity to reinforce the **String slicing** concept.

# 5️⃣ Palindrome Checker

## Solution

```python
# ============================================================
# Question 5: Palindrome Checker
# ============================================================

# Ask the user to enter a word
word = input("Enter a word: ")

# Reverse the word using slicing
reverse = word[::-1]

# Compare the original word with the reversed word
if word == reverse:
    print(word, "is a Palindrome.")
else:
    print(word, "is not a Palindrome.")
```

### Example 1

```text
Enter a word: madam

madam is a Palindrome.
```

Because:

```text
Original = madam
Reverse  = madam
```

Both are the same.

### Example 2

```text
Enter a word: python

python is not a Palindrome.
```

Because:

```text
Original = python
Reverse  = nohtyp
```

They are different.

## ⭐ Bonus – Character Analyzer

### Solution

```python
# ============================================================
# Bonus: Character Analyzer
# ============================================================

# Ask the user to enter some text
text = input("Enter text: ")

# Counters for different types of characters
uppercase_count = 0
lowercase_count = 0
digit_count = 0
space_count = 0

# Loop through every character in the text
for letter in text:

    # Check whether the character is uppercase
    if letter.isupper():
        uppercase_count = uppercase_count + 1

    # Check whether the character is lowercase
    elif letter.islower():
        lowercase_count = lowercase_count + 1

    # Check whether the character is a digit
    elif letter.isdigit():
        digit_count = digit_count + 1

    # Check whether the character is a space
    elif letter.isspace():
        space_count = space_count + 1


# Display the results
print("\nCharacter Analysis")

print("Uppercase Letters =", uppercase_count)
print("Lowercase Letters =", lowercase_count)
print("Digits =", digit_count)
print("Spaces =", space_count)
```

### Example

Input:

```text
Enter text: Python Class 2026
```

Output:

```text
Character Analysis

Uppercase Letters = 2
Lowercase Letters = 9
Digits = 4
Spaces = 2
```

## 👨‍🏫 Teaching Points to Emphasize

### 1. Strings can be processed character by character

```python
for letter in text:
    print(letter)
```

This is one of the most important concepts students should take away.

### 2. Counters are extremely useful

The pattern:

```python
count = 0

for item in data:
    if condition:
        count = count + 1
```

will appear repeatedly in Python programming.

### 3. Conditions can be combined with String methods

For example:

```python
if letter.isupper():
```

This allows the program to make decisions based on the type of character.

### 4. `print()` and `return` are different

At this stage, students are still learning programming fundamentals, so it's useful to reinforce that `print()` **displays** a result, while `return` will become important when you introduce **Functions**.

### 5. There can be multiple ways to solve the same problem

For reversing a String, students first learn the **logic using a loop**:

```python
reverse = character + reverse
```

and then learn Python's concise slicing approach:

```python
word[::-1]
```

This helps them understand both **programming logic** and **Python-specific features**.
