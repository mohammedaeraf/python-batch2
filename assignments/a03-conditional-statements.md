# 🧪 Lab Assignment 02 – Conditional Statements in Python

## 📘 Instructions

1. Write each program in a separate Python file.
2. Use `if`, `if-else`, or `if-elif-else` statements wherever appropriate.
3. Accept input from the user.
4. Display clear and meaningful output.
5. Test your programs with different input values.

---

## 1️⃣ Even or Odd Number

**Problem:**

Write a Python program that accepts a number from the user and checks whether it is **Even** or **Odd**.

**Hint:**

```text
Use the modulus (%) operator.
If number % 2 == 0, it is Even.
```

### Sample Output

```text
Enter a Number: 15

15 is an Odd Number.
```

---

## 2️⃣ Pass or Fail

**Problem:**

Write a Python program that accepts a student's marks and displays whether the student has **Passed** or **Failed**.

### Condition

* Marks **40 or above** → Pass
* Marks **below 40** → Fail

### Sample Output

```text
Enter Marks: 72

Result: Pass
```

---

## 3️⃣ Grade Calculator

**Problem:**

Write a Python program to display the grade based on the marks entered by the user.

| Marks        | Grade |
| ------------ | ----- |
| 80 and above | A     |
| 60 – 79      | B     |
| 40 – 59      | C     |
| Below 40     | D     |

### Sample Output

```text
Enter Marks: 68

Grade = B
```

---

## 4️⃣ Largest of Three Numbers

**Problem:**

Write a Python program that accepts three numbers from the user and displays the **largest number**.

**Hint:**

Use the `and` logical operator to compare multiple conditions.

### Sample Output

```text
Enter First Number: 45
Enter Second Number: 82
Enter Third Number: 36

Largest Number = 82
```

---

## 5️⃣ Electricity Bill Calculator

**Problem:**

Write a Python program to calculate the electricity bill based on the number of units consumed.

### Tariff

| Units Consumed  | Rate per Unit |
| --------------- | ------------- |
| Up to 100 units | ₹5            |
| 101 – 200 units | ₹7            |
| Above 200 units | ₹10           |

### Formula

```
Bill = Units × Rate
```

### Sample Output

```text
Enter Units Consumed: 150

Rate per Unit = ₹7
Total Bill = ₹1050
```
