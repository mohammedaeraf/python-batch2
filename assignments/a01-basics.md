# 🧩 Assignment 01 – Python Basics

## 📘 Instructions

1. Write each program in a separate Python file.
2. Use meaningful variable names.
3. Accept input from the user wherever applicable.
4. Display clear and user-friendly output.
5. Test each program before submission.

---

## 1️⃣ Find the Perimeter of a Rectangle

Write a Python program to calculate the **perimeter of a rectangle**.

**Hint:**

Perimeter of a rectangle:

```text
perimeter = 2 * (length + width)
```

**Sample Output**

```text
Enter Length: 10
Enter Width: 5

Perimeter = 30
```

---

## 2️⃣ Find the Square of a Number

Write a Python program to calculate the **square** of a number entered by the user.

**Hint:**

```text
Square = Number × Number
```

**Sample Output**

```text
Enter Number: 8

Square = 64
```

---

## 3️⃣ Find the Area of a Circle

Write a Python program to calculate the **area of a circle** using the radius entered by the user.

**Hint:**

Use:

```python
pi = 3.14
```

Formula:

```text
Area = π × radius × radius
```

**Sample Output**

```text
Enter Radius: 7

Area = 153.86
```

---

## 4️⃣ Swap Two Numbers Using a Third Variable

Write a Python program to swap the values of two variables using a third variable.

**Sample Output**

```text
Before Swapping

A = 10
B = 20

After Swapping

A = 20
B = 10
```

---

## 5️⃣ Simple Calculator

Write a Python program that accepts two numbers from the user and displays:

- Addition
- Subtraction
- Multiplication
- Division

**Sample Output**

```text
Enter First Number: 20
Enter Second Number: 5

Addition = 25
Subtraction = 15
Multiplication = 100
Division = 4.0
```

## 🎯 Learning Outcomes

After completing this assignment, students will be able to:

- Use variables to store data.
- Accept user input using `input()`.
- Perform arithmetic calculations.
- Apply mathematical formulas in Python programs.
- Display formatted output using `print()`.
- Build confidence in writing simple Python programs.
