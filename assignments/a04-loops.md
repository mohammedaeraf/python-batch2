# 🧩 Assignment 03 – Loops in Python

## 📘 Instructions

1. Write each program in a separate Python file.
2. Use meaningful variable names.
3. Use either a `for` loop or a `while` loop as appropriate.
4. Display clear and user-friendly output.
5. Test your programs with different inputs before submission.

---

## 1️⃣ Print Numbers from 1 to 20

**Problem:**

Write a Python program to display numbers from **1 to 20** using a `for` loop.

### Sample Output

```text
1
2
3
4
...
20
```

---

## 2️⃣ Multiplication Table

**Problem:**

Write a Python program that accepts a number from the user and displays its multiplication table from **1 to 10**.

### Sample Output

```text
Enter a Number: 7

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```

---

## 3️⃣ Sum of First N Natural Numbers

**Problem:**

Write a Python program that accepts a number **N** from the user and calculates the sum of all numbers from **1 to N**.

**Hint:**

```text
Use a variable named total and initialize it to 0.
```

### Sample Output

```text
Enter N: 10

Sum = 55
```

---

## 4️⃣ Count Even and Odd Numbers

**Problem:**

Write a Python program to display all numbers from **1 to 20** and count how many are **Even** and **Odd**.

### Sample Output

```text
Even Numbers = 10
Odd Numbers = 10
```

---

## 5️⃣ Factorial of a Number

**Problem:**

Write a Python program to calculate the **factorial** of a number entered by the user.

**Hint:**

```text
Factorial of 5 = 5 × 4 × 3 × 2 × 1 = 120
```

### Sample Output

```text
Enter a Number: 5

Factorial = 120
```

# 🎯 Learning Outcomes

After completing this assignment, students will be able to:

* Use `for` and `while` loops effectively.
* Generate number sequences using `range()`.
* Perform calculations inside loops.
* Solve repetition-based programming problems.
* Use nested loops to generate simple patterns.
